2. **Localized noun != localized conversation:** B2 smoke asserts TL `doktor` from `common/media/conversation/backstory/shared/TL/facts.json` via legacy `PNC.Conversation.TextLoader`. That file is a real catalog, not a literal Tagalog word hardcoded into the fact-provider Lua; nevertheless it bypasses the project-wide Core-backed custom translation registration. B5 `PNC_SemanticDialogueLocalResponse_Questions.lua` constructs whole English sentences for `semantic.question.backstory.known/suspected/ambiguous/refusal`; `PNC_SemanticDialogueInput_Presentation_Responses.lua::semanticTranslationKey` has no mapping for these, and `EN/TL/Conversation/Semantic/Responses.json` has no full-sentence backstory keys. The argument selector omits new `response.args.content`. Thus TL may show English grammar with a TL fact noun. Existing `PNC.Translation` already routes registered Hoomans custom catalogs through `PsychopatzCore/Translation/PsychopatzCustomTranslationManager.lua`; extend/reuse it, not another translation layer.
3. **Privacy:** `PNC_SemanticDialogueBackstoryFactSource.lua::projectedFact` and `Memory.BuildAuthorizedBackstoryFacts` resolve the canonical generated backstory when the discovered player descriptor is merely `suspected`. This risks upgrading uncertain hearsay to actual private truth in a response and optional PBrainZ payload. Guard by status/provenance with authoritative server-only resolution and per-player isolation.
4. **Test/acceptance mismatch:** user-provided `python3 -m unittest discover -s tools/semantic_harness/tests -v` exited 1 (251 run, 30 errors), whereas the B6 ledger claims full Python harness passed. The Lua broad suite reported 839/853, 14 failures classified preexisting by the agent but not independently reproduced/compared. Synthetic B6 payload figures 2,664 bytes/NPC, 269,760 for 100, 2,706,037 for 1,000 are valid *reported harness figures*, not native PZ ModData/performance proof. Existing backstory 50-familiarity gate shared across kinds is not differentiated gradual access. Do not mark H goal accepted until evidence is reconciled.
5. **Harness usage limited:** B0/B2/B3 real worker tests exist, and privileged `BACKSTORY_FACT` diagnostic exercises provider truth, but absence of full generated CodeBuilder→fresh worker→actual NPC text→server disclosure→dossier EN/TL trace means system-level authoring and conversation acceptance remain open.
