## Ownership invariants verified

- Known game events enter as grounded semantic events after source-domain validation; generated text is never reparsed into the known event.
- Freeform language remains on the existing NLU/parser/router path.
- Lifecycle ModData stores bounded meaning, unresolved state and compact references, never ordinary rendered transcripts.
- No Player × NPC cross-product is preallocated, and no per-NPC/per-tick lifecycle scan exists.
- Private pair state is projected only to the owning player; shared world events use canonical IDs.
- ConversationBlocks and gameplay domains retain permission/effect authority.
