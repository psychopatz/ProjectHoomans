Project Hoomans Translation Guide
=================================

Project Zomboid Build 42.20 layout
- Translation catalogs are packaged directly at
  `common/media/lua/shared/Translate/<LANG>/*.json`.
- `UI.json` is the canonical UI and conversation catalog. Maintain it directly;
  it is not generated from a repository-root source tree.
- `Sandbox.json` is the canonical sandbox-options catalog.
- Every UI entry must use a stable `UI_` key and every catalog must remain a
  valid JSON object containing string keys and string values.

Conversation content layout
- Greeting selection definitions are reusable content and live at
  `common/media/lua/client/PNC/Conversation/Content/Greetings/...`.
- Conversation runtime code, registries, lifecycle logic, and UI integration
  live in `42.20/media/lua/...`.

Greeting categories
- FirstMeet
- Acquaintance
- Member
- Lover

Time variants
- Dawn
- Sunrise
- Sunset
- Dusk
- Twilight

Adding a greeting
1. Add a stable `UI_PNC_Greeting_...` key and prose directly to the language's
   `UI.json` catalog.
2. Add only that key to the matching reusable greeting definition under
   `common/media/lua/client/PNC/Conversation/Content/Greetings/...`.
3. Run the conversation smoke test to verify every referenced key is present.

Adding a relationship category
1. Add the runtime category to
   `42.20/media/lua/client/PNC/Conversation/PNC_ConversationRelationship.lua`.
2. Add its reusable greeting definitions under `common/media/.../Greetings`.
3. Require the definition bootstrap from the Build 42.20 conversation runtime.

Adding another language
1. Create `common/media/lua/shared/Translate/<LANG>/UI.json` using the same keys
   as the English catalog.
2. Translate values only; do not rename keys.
3. Add the corresponding `Sandbox.json` when sandbox labels are translated.
